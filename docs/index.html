Analyst Bench · Pilot-1 · 2026-10

Four AI analyst agents, one set of business questions

Nine analysis tasks on a synthetic mobile-game warehouse (300,000 accounts). Each product answered every task twice in fresh sessions, 20 minutes each. Blind answers were reviewed by AI judges from the other vendors (GPT, Claude, Grok) and scored by a deterministic grader.

Method and disclosures
  1. Products and settings: Codex (gpt-6.1-sol, reasoning high), Claude Code (claude-opus-5-5, high), Grok Build (grok-4.7, high), Antigravity CLI (gemini-3.8-flash-high). All ran on personal subscriptions, in a fresh session per attempt, inside a local sandbox that could reach only the product's own inference service.
  2. Judging: each answer was judged by the panel judges from the other vendors: two judges for Codex, Claude Code and Grok Build, three for Antigravity (majority). Where two judges disagree, the lenient version takes the reading more favorable to the answer and the strict version the less favorable one. Automatic arithmetic checks were never overridden.
  3. Speed-adjusted score: for passing answers only, score × (1 + 10% × (1 − time / 1,200 s)). The rule was set during wave 2, when some timings but not the wave-2 accuracy were known.
  4. Review protocol change: the plan was owner review. Because of the workload (722 claim verdicts), it changed to AI judging after provisional scoring and before any review decision, and later to the cross-vendor panel.
  5. Grader fixes after wave-1 results: citing the provided task file counts as valid evidence; ISO interval notation is parsed correctly (this restored 20 points on each Codex Q07 answer).
  6. Open policy point, left unchanged: one Grok Build Q12 attempt hit the time cap, but the files saved by then scored 89–93 and the grader counts it as a pass. Under the design's rule that terminal failures count as failures, Grok Build's core accuracy would be 8/14 (lenient) and 7/14 (strict).
  7. Product differences: Antigravity's server-side web search could not be disabled; it used it 0 times in the scored attempts. Its sandbox also allowed localhost for its language server. Gemini CLI was blocked by Google's personal-account policy, so Antigravity CLI is the Google product. Grok had seen the reference answers earlier as the wave-1 judge (training and memory off).
  8. Run conditions: local sandbox, not a VM; both wave-1 repetitions ran on the same day; the quota pause threshold changed during wave 1.
  9. Scale: 18 attempts per product on one dataset. Differences are descriptive, not statistically established.
